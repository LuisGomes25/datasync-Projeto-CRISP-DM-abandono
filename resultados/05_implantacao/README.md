# Implantação

`lista_priorizada_escolas.csv`: escolas por etapa, com probabilidade calibrada e faixa de prioridade.

| Faixa | Escolas da etapa |
|---|---|
| 1 | 5% com maior probabilidade |
| 2 | de 5% a 10% |
| 3 | de 10% a 20% |
| 4 | demais |

A lista é **por etapa**: a mesma escola pode aparecer em faixas diferentes no ensino médio e nos anos finais. Serve para priorizar acompanhamento e busca ativa, não para classificar escolas. Atualizar a cada novo Censo Escolar.
